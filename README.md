# 🕊️ OFFLOAD (STAM 14566)
### AI-Enabled Real-Time Stress and Trauma Assessment Module
**Problem Statement:** Design & develop an AI-enabled Real-Time Stress & Trauma Assessment Module (STAM) for the **National Helpline Against Atrocities (NHAA 14566)**, Department of Social Justice & Empowerment (DoSJE), Government of India.  
**Built for:** Smart India Hackathon (SIH)

---

## 🌟 Tagline
> **"RELEASE YOUR THOUGHTS. FIND YOUR FLOW."**

---

## 🚀 Key Features

1. **Multi-Channel Standardized Triage:**
   - **Helpline 14566 IVRS Voice Simulator:** Real-time speech pitch jitter extraction, hesitation pause detection, and ambient distress evaluation.
   - **Interactive Web Portal:** Client-side zero-knowledge encrypted incident reporting wizard with automatic SC/ST (PoA) Act section classification.
   - **Deeply Coded Mobile App OS Simulator:** Standalone interactive mobile UI with 5 sub-screens, voice lab visualizer, nearby safe shelters, and 3-second hold-to-activate emergency SOS beacon.

2. **Explainable AI Stress Vulnerability Index (SVI 0–100):**
   - Quantifies acute trauma, fear/threat, anxiety, and suicidal ideation with red-flag escalation.
   - Explainable forensic trigger keyword extraction.

3. **Multi-Agency Ecosystem Integration:**
   - **Tele-MANAS (14416):** Direct psychiatric & psychological trauma counseling links.
   - **District SP SC/ST Protection Cells:** Automated high-priority armed escort dispatch.
   - **DLSA (District Legal Services Authority):** Free legal defense & Special Court advocate linkage.
   - **Statutory Relief Schedule:** Automatic compensation computation under PoA Rules 2016 Annexure-I.

4. **Victim Safety & Privacy:**
   - **Discreet Emergency Camouflage:** Press `Esc` to instantly disguise the screen as a functional scientific calculator (unlock code: `14566 =`).
   - **Real Browser GPS:** Live coordinates detection with Leaflet map rendering.
   - **Google Gemini AI API Integration:** Live contextual legal & psychological support with full offline fallback.

## 💻 How to Run Locally

1. Clone this repository:
   ```bash
   git clone https://github.com/<your-username>/offload-stam-14566.git
   cd offload-stam-14566
   ```

2. Start a local HTTP server:
   ```bash
   python3 -m http.server 8080
   ```

3. Open in your browser:
   ```
   http://localhost:8080/
   ```

## 🌐 Deploy to GitHub Pages (1-Click Live)

1. Go to your GitHub repository **Settings** → **Pages**.
2. Under **Build and deployment** → **Source**, select `Deploy from a branch`.
3. Select branch: `main` and folder: `/ (root)`, then click **Save**.
4. Your platform will be LIVE at:
   ```
   https://<your-username>.github.io/offload-stam-14566/
   ```
